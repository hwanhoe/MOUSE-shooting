# 🎯 스카이 헌터: 플라잉 타겟 (Sky Hunter: Flying Target)

마우스 클릭으로 날아가는 다양한 표적을 맞추는 박진감 넘치는 웹 아케이드 슈팅 게임입니다. 별도의 설치나 웹 서버 없이 **`index.html` 파일을 더블 클릭**하기만 하면 브라우저에서 바로 플레이할 수 있습니다.

---

## 🎮 실행 방법
1. 본 폴더에 있는 **`index.html`** 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 웨일(Whale) 등 웹 브라우저로 엽니다.
2. 메인 화면에서 **[게임 시작]** 버튼을 누르면 카운트다운과 함께 게임이 시작됩니다.

---

## 🕹️ 조작 방법
- **마우스 이동**: 조준선(크로스헤어) 이동
- **마우스 좌클릭**: 사격 (총알 발사)
- **마우스 우클릭 / R 키**: 재장전 (최대 탄약 6발)
- **P 키 / ESC 키**: 일시정지 (PAUSE)
- **우측 상단 🔊 / 🎵 아이콘**: 효과음 및 배경음악 On/Off 토글

---

## 🎯 표적물 종류 및 특징
| 표적명 | 특징 | 격추 조건 | 점수 / 효과 |
| :--- | :--- | :---: | :--- |
| **일반 드론** (빨강/흰색) | 중간 속도로 비행하는 기본 타겟 | 1발 | **+100점** |
| **황금 스피더** (황금빛) | 작고 매우 빠른 속도로 날아가는 특수 타겟 | 1발 | **+300점** (콤보 점수 대량 획득) |
| **철갑 타겟** (파란 육각형) | 단단한 실드를 장비한 중장갑 타겟 | 3발 | **+500점** (1~2타 시 도탄 불꽃) |
| **타임 캡슐** (에메랄드 시계) | 시간 보너스를 주는 희귀 타겟 | 1발 | **+3초 시간 추가!** (+50점) |
| **폭탄 드론** (해골/가시) | **절대 쏘면 안 되는 위험 표적!** | 1발 | **-5초 시간 감소, -200점 감점, 콤보 리셋** |

## ⚡ 게임 핵심 시스템
1. **제한 시간 (60초)**:
   - 기본 60초가 주어지며, 타임 캡슐을 맞추면 시간을 연장할 수 있습니다.
   - 시간이 10초 이하로 떨어지면 타이머가 붉게 점멸하며 긴급 경고음이 울립니다.
2. **콤보 & 배율 시스템**:
   - 빗맞히지 않고 연속 명중할수록 배율이 상승합니다 (`x1.0` ➔ `x1.5` ➔ `x2.0` ➔ `x2.5` ➔ `x3.0`).
   - 공중에 빗맞히거나 폭탄을 쏘면 콤보가 초기화됩니다.
3. **탄약 시스템 (6발)**:
   - 한 탄창에 6발이 장전되어 있으며, 탄약을 모두 소모하면 재장전(R 또는 우클릭)해야 합니다.
4. **풍부한 타격감 & 연출**:
   - Web Audio API 기반 순수 프로그래밍 효과음 (총소리, 도탄음, 콤보 상승음, 폭발음, 경쾌한 칩튠 BGM).
   - 반동, 총구 섬광, 탄창 리로드 애니메이션, 화면 흔들림(카메라 셰이크), 파티클 폭발.
5. **최종 등급 (Rank)**:
   - 최종 점수 및 명중률에 따라 **S, A, B, C, D** 등급이 부여되며, 최고 점수는 브라우저(LocalStorage)에 자동 저장됩니다.
